# ScaryMonkey Prototype Project
A gameplay mechanics prototype based on [Gorilla Template](https://github.com/NormalVR/GorillaTemplate?tab=readme-ov-file). This prototype focuses on building a networked enemy behavior and a simple gameplay loop.

### Gameplay
Get through the dark maze without getting caught by those fireflies!

### Features
In addition to what the Gorilla Template provided, the following features were implemented in this project
- Generic Simple State Machine with state callback actions
- Synchronized State Machine that requires certain Normcore components for synchronization
- Enemy with networked chase behaviors and audiovisual effects, utilizing the state machines mentioned above. 
- Simple player respawn volume
- Simple enemy spawner manager
- Scene and SFX changes
- Other minor changes (Eg. screen debug controls improvement)
